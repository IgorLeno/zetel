# Rejected patterns

- Instalar Spec Kit, Superpowers ou pacotes de skills completos.
- Bootstrap always-on ou skill check antes de toda resposta.
- Worktree obrigatoria para toda mudanca.
- Subagentes obrigatorios ou loop autonomo de varias tarefas.
- Persistir ou retomar transcript.
- Issue tracker externo como fonte primaria.
- Hooks que editam, commitam ou fazem push.
- Force push, refspec forcada, exclusao remota ou reescrita de historico.
- E2E live e chamadas OpenRouter sem autorizacao e budget.
- Usar grafo ou memoria como autoridade superior aos arquivos-fonte e ao Git.
